# Python Mini Projects

A collection of small Python projects built for learning, experimentation, and practical programming practice. This repository includes mini applications covering game development, command-line tools, and simple management systems.

## Projects Included

- Legends_of_The_Forgotten_Realm  
  A text-based fantasy RPG with character creation, combat, inventory, shop system, world exploration, leveling, and save/load mechanics.

- Dental_Clinic_System  
  A clinic appointment management system built for scheduling patient appointments and handling dental clinic workflows.

- Tic-Tac-Toe  
  A simple command-line Tic-Tac-Toe game for two players.

## Repository Structure


## How to Run

Each project can be run separately using Python:

```bash
python main.py
```

For the Tic-Tac-Toe game:

```bash
python tictactoe.py
```

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- JSON data storage
- Command-line interface (CLI)
